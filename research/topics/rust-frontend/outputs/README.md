# Rust Frontend 输出层

这里保存从专题研究稳定转出的交付物。所有内容共同读取上一级 [`claims.yml`](../claims.yml)，并通过 Source ID 回到证据账本。

- `brief/`：供决策和审阅使用的 Markdown 研究 Brief。
- `booklet/`：用于系统性主题阅读和专项研讨的小册子、阅读清单、研讨指南与能力矩阵。
- `slides/`：架构与生产成熟度演示的逐页 Markdown 稿、可运行的 `slidev/` 工程和导出的 PPTX。
- `chapter-handoff/`：按章节契约拆分的可写入素材。
- `figures/`：Brief、PPT 与书稿共同复用的 SVG 图。
- `deliverables.yml`：交付状态和文件清单。

原始转写仍留在 `source/transcripts/`，输出层不把 D 级口述线索升级为事实。
