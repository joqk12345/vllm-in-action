# Rust Frontend 主题研究小册子

本目录是专题研究的第五种正式输出，位于 Research Brief 与正式书稿之间。

- [`rust-frontend-topic-booklet.md`](rust-frontend-topic-booklet.md)：问题驱动的主题综合读物。
- [`seminar-guide.md`](seminar-guide.md)：60～90 分钟专项研讨主持方案。
- [`reading-list.md`](reading-list.md)：按研究问题组织的分层阅读路径。
- [`capability-matrix.yml`](capability-matrix.yml)：代表性能力的动态、机器可读状态。

小册子主体只吸收相对耐久的架构、方法和工程判断。版本、roadmap checkbox、parser 列表等高频变化信息留在能力矩阵和 [`../../tracking/`](../../tracking/) 中。

更新顺序：

```text
上游漂移
  → tracking 分诊
  → capability matrix
  → claim spine
  → 小册子动态附录
  → 必要时修改主体
```

不得从 roadmap 的 `checked` 直接推导出 `released` 或 `tested`。
