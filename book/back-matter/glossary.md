# 术语表

| 术语 | 英文/缩写 | 本书中的定义 |
|---|---|---|
| 首 token 延迟 | Time to First Token, TTFT | 从请求到达服务到返回第一个输出 token 的时间 |
| token 间延迟 | Inter-Token Latency, ITL | 流式生成过程中相邻输出 token 之间的延迟 |
| KV Cache | Key-Value Cache | 自回归生成时复用历史注意力键值的缓存 |
| 服务级目标 | Service Level Objective, SLO | 对延迟、可用性等指标设定的可测目标 |

> 术语定义必须随正文和上游语义复核，不追求一次填满。
