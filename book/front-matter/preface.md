# 前言

《vLLM 深入研究：从 Token 到生产服务》面向已经会使用 Python、Linux 和 GPU，却希望真正理解推理系统的工程师。它不是参数手册：参数、默认值和 backend 会变化；可迁移的是从工作负载与 SLO 出发，沿请求、调度、状态、算子、通信直到生产反馈的推理方法。

本版正文依据本地 vLLM 仓库 commit `fe1c317157d4478fdc0e02096447e61305b871e9`（`v0.27.2rc0-129-gfe1c317157`）核对，验证日期为 2026-08-16。当前 commit 位于 release candidate 之后的开发线上，不能把书中的实现细节无条件外推到旧 tag 或未来版本。每章开头的 verified 标记给出代码快照；命令、默认值和兼容性仍应回到实际部署 tag 的源码、测试与官方文档复核。

全书采用一条稳定主线：

> workload → SLO → engine mechanism → memory/compute/communication → experiment → production feedback

阅读有三种方式：初学系统的读者按 1—16 章顺序；性能工程师重点阅读 2、4、8—13 章；线上值班和平台负责人重点阅读 6、13—16 章。附录提供源码地图与实验手册，网站版支持全文搜索与前后章导航。

事实分为四类：当前源码可验证事实、官方设计事实、实验观察和工程建议。本书不伪造未执行的 GPU 数字；需要硬件验证的地方给出实验设计，由读者在自己的模型和拓扑上建立证据。已有专题研究（线性/混合注意力、投机解码、llm-d、Rust frontend）保留在 `research/topics/`，成熟结论才进入正文。

本书由人类发起并使用 AI 辅助整理与写作。公开发布前，提交者必须逐行审阅、完成技术审校、选择许可证，并对所有性能结论提供可复现实验。
